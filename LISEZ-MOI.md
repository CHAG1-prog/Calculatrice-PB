# Calculatrice

Application Android (testée sous GrapheneOS), version 2.3.

## Télécharger

[Calculatrice.apk](https://github.com/CHAG1-prog/Calculatrice-PB/raw/main/Calculatrice.apk)

## Installer

1. Télécharge le fichier ci-dessus sur le téléphone.
2. Ouvre-le depuis l'application « Fichiers ». Le téléphone demande d'autoriser cette application à installer des applications inconnues : autorise, installe, puis retire l'autorisation.
3. Pour une mise à jour, installe le nouveau fichier par-dessus l'ancien, sans désinstaller.

## Vérifier le fichier

Empreinte SHA-256 de Calculatrice.apk :

`aabfb42492acc340e9615fa38cb85bf6e08ac11a5e969f773454a86e1fada2a4`

L'application demande uniquement la permission du microphone (pour des fonctions audio facultatives) ; toujours aucun accès à Internet ni au stockage.
